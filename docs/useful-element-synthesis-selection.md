# P1 synthesis selection readiness

Selection policy is deliberately a research-only release. For each active pattern candidate and each balance direction, report five separate method objectives, exact participant roles, baseline/conditional climate membership, possible supply contacts, mediation routes and remedy motifs. Pattern anchors are not favorable elements, supplementary route presence is not confirmed efficacy, and outside-candidate membership is not unfavorable. Missing directions remain unknown. No numerical ranking, universal precedence, vote or mutable authorization. Public synthesis gains additive selectionReview; its root decision fields remain null. A validated future decision release must separately establish effective action, method-specific source agreement and cross-method precedence.

The source audit now distinguishes partial candidate coverage from a common hypothesis, rejects duplicate/missing projections and enforces the case as well as probe denominator. No classical rules or force thresholds are tuned on absent native evidence.
