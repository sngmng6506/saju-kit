# Balance route review v1

## Scope and responsibility
Reuse the existing root-dynamics graph, support-network categories, quantitative-v3 scenarios and multihop-interaction-v1 shared-capacity allocator. The previous balance candidate API and priority API are unchanged. No new fitted weights, force law, threshold or useful-element authority. This is an extended competing-route reservation model, not a simulation of actual elemental transfer or a counterfactual addition of an element.

Retain existing wealth/officer/resource paths, including bounded wealth->officer->resource->day, officer->resource->day, direct resource, wealth and officer burdens, resource-controls-output and wealth-controls-resource. Extend with peer assistance (anchored local same-element support hypothesis, not a generating edge), output drain (reverse budget representation of day->output, not reversed generation), peer-controls-wealth, officer-controls-peer, output-controls-officer, peer-generates-output, output-generates-wealth, wealth-generates-officer. The extension control/generation edges are literal distinct-slot graph edges, without requiring all actors anchored; inherited anchoring rules remain unchanged. All routes compete in a single ledger for a scenario, irrespective of assumed direction. One nominal origin budget, shared capacity across non-day nodes; no redistribution or added support mass. No self loops, repeated physical slots or day mass. Each path has one mechanism identifier. Do not sum direct, coverage and competing summaries into a net score. A competing relation is a neutral review dimension, not necessarily an adverse effect (e.g. wealth generates officer). Different candidate summaries can refer to the same reservation, so they must not be summed across candidates. Category-level aggregation does not establish that every effect is carried by the same natal stem.

The weak-branch coverage diagnostic requires both candidates to have positive direct reservation in every standard and neutral scenario; one must have a strict superset of the other's positively reserved burden categories. Both adjacent and one-gap locality must identify the same singleton before robustFocus is nonempty. The criterion is structural coverage, not proof of excess, relief, causal efficacy or superiority. No analogous strong-branch focus rule has been proposed: its empty focus means not evaluated, not evidence against any candidate. Do not promote this heuristic on exposed examples. All original candidates remain available.

## Executed evaluation
Actual 18-module V8 graph (unused throwing calendar stub) executed on 100 historical charts in both conditional directions and four previously exposed textual useful-element controls in the author's direction. 11,808 historical scenario/locality evaluations; 419,328 path reservations and 134,160 ledger entries (excluding the four controls). Origin budgets, accepted <= requested, distinct physical slots, shared capacity and no mutation verified. Compact cohort result retains per-chart path counts and focus; full candidate ranges retained for four controls. 11 of 100 hypothetical weak branches yield robust focus, but five have a fixed strong prior, six unresolved, and zero fixed weak. Thus there is no live weak focus in this historical cohort. This is not a direction or useful-element accuracy claim.

BU-X01: in adjacent mode resource has positive direct reservation 1,831,253–5,079,006, output control 1,831,253–4,820,051, officer mediation 2,339,688–3,684,234, wealth mediation 731,707–1,047,601. Peer direct zero; wealth control of resource remains positive. One-gap mode yields resource focus because peer direct also exists. No robust focus across both localities; prior single-dominant review incorrectly focused peer, new review abstains, not a successful selection. BU-X02: no direct peer under either locality and no robust focus; source selects peer. BU-X03/04: route observations present, strong focus not evaluated. Four controls are exposed, not independent holdout, and no new source validation was performed. No production ranking adopted.
