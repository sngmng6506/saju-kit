# Support network v1

Additive neutral core API: `analyzeSupportNetwork({saju})`. Reuses root-dynamics nodes and edges. Classifies nodes relative to day master using the existing five-element direction convention. Resource records preserve direct generation to day, incoming wealth control and officer generation, outgoing output control, rooted/principal evidence and local anchored wealth threats. Burden records distinguish output, wealth and officer, preserving edge direction. Chains require three distinct physical slots: officer-resource-day (generate/generate), wealth-resource-day (control/generate), resource-output-officer (control/control), output-wealth-officer (generate/generate). The control/control chain does not imply net protection or harm. Local means each edge spans at most one pillar column. Anchored means rooted visible stem or principal branch node. All paths are hypothetical structural observations; no effective transfer, cancellation, or additive path score. Missing hour returns observed nodes only. No strength policy or consumer changed. Uses existing natal input validation. No private input echo.

Motivation: [Wei comparison](ordinary-wei-reference-v1.md), notably W24 versus W04/W19. These examples cannot justify a universal pressure veto. The new fields distinguish resource opposition, output regulation and burden channels before a new directional policy. Five new test bodies passed using actual source in a V8 ESM adapter; all 26 Wei records evaluated. Native Node regression pending. No special-pattern or yongsin inference.
