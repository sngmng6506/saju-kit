## API and time contract
`analyzeMonthCommand({saju,birth})`. Birth uses the existing getSaju input contract; exact hh/mm required to compute. Existing clock policy remains unchanged. Reject inconsistent supplied pillars against recomputed birth; unsupported historical clock yields unresolved (or existing calendar error when the month/year boundary is disputed). Missing birth or both hh/mm absent yields no hypotheses. Existing calendar restrictions apply, including 23:00. Solar table instants have minute precision, UTC+9 wall convention. No inference from a two-hour pillar, cycle year, or source date without enough metadata. A chart missing hour can still return month evidence if exact independently supplied birth is consistent with every supplied pillar; completeHour reports input-chart completeness.

Find adjacent even-index solar terms with start inclusive/end exclusive. Store elapsed and duration in integer minutes. Two clearly separate computational conventions: literal-days (elapsed 24-hour periods; any >30-day tail unresolved); normalized-30 (map actual interval to nominal 30 days using exact cross multiplication, experimental engineering sensitivity). Neither is asserted as the unique historical interpretation. Results always conditional; commandResolved and effectsConfirmed remain false, direction null. allAvailableElementsAgree is agreement among available hypotheses only; allHypothesesAvailable must be checked separately. Source with unresolved order or incomplete nominal duration cannot generate a timed command. Report literal hidden-stem match without modifying natal hidden stems.
