Opt-in `analyzePatternOutcomeIntegrated` / `pattern-outcome-integrated-v1`. This is not V10 decision authority. Prior public APIs remain unchanged.

## Pipeline

Build V5 once. For storage projections admitted by V5 only, replay the omitted V2 group/hidden, V3 secondary role and V4 regulation stages using the original request-local core evidence and strength projection. All subsequent rules carry unresolved storage access/family conditions. Ordinary candidates are not replayed. Then apply V6 winter exception and assistant route extension. Generate position, compound (including motifs), assistant, purity, clarity and extension projections from the same final witness set. Climate only on applicable winter metal charts; no extra pattern/strength rerun. The previous extension API's position projection referred only to original V9 witnesses; this integrated policy closes that gap.

Storage provenance is not a new hidden root or an effective monthly command. Applying family rules uniformly is a structural hypothesis, not a proof that storage family is valid. Winter exception still requires a literal monthly hidden hurting anchor; storage admission does not relax it. No numerical score or decision.

## Integrity

Check duplicate rule/witness identity, anchor and participant IDs against actual occurrences/group IDs, rule/witness authority, storage condition propagation, exact position witness coverage, derived review status and final authority. Invalid results are reported, not silently repaired. This is a structural consistency screen, not validation of effective force, exhaustive semantics or correctness of classical doctrine. No consumer migration.
