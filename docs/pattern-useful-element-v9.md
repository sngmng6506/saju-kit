# Stem force evidence v1 / pattern v9

Source basis: [論十干得時不旺失時不弱](https://donglishuzhai.net/chapter/3719.html), [論用神格局高低](https://www.kaucim.ai/bazi/ziping-zhenquan/lun-yong-shen-ge-ju-gao-di). The second chapter discusses relative force of the day, controller, and controlled actor, and distinguishes 辛's 酉祿 from 丁's 酉長生. Literal hidden roots and twelve-stage context must remain distinct; the stage convention is the existing versioned core. The first chapter electronic witness returned 502 on full fetch; indexed text and parallel witnesses support the root/season distinction.

The core API analyzeStemForceEvidence({saju}) uses existing root-dynamics and interaction observations. All visible and hidden occurrences have stable IDs matching pattern route observations; hidden occurrences share an elemental branch graph node, not independent resource budgets. Each row exposes exact/same-element roots, substantial/residual roles, location, clash exposure, month stage, seasonal/principal relation, peer and generating/controlling contacts, outgoing generation/control and protection/mediation paths for every target. Distinct physical slots required for paths. A root not exposed to an observed clash is not proven intact; group/combination contact not proven transformation. Missing hour makes absence unknown. No summed score, threshold, effective force class, or final useful/assistant selection. Root evidence labels describe evidence, not force. Day reference remains explicit.

Pattern v9 adds stemForce and patternForce to frozen v8. Role bindings reuse core evidence by occurrence ID; reverse legacy links are normalized to actual source/target; graph witnesses preserve named roles. No reclassification or promotion to authority/transit. No changes to consumer scores. No special charts.

Executed 18 actual source modules (adapted ESM, not full public wrapper) for 81 reference charts, 240 complete/partial factorial charts and one focused classical schematic. 4363 occurrences (3195 hidden), 7816 legacy route links, 3772 role witnesses, 32419 protection/mediation paths, 427 clash-exposed-only root labels and 215 unknown substantial-root observations. Identity, mutation, incomplete-hour and no-authority invariants checked. No independently annotated effective force targets; this is structural coverage, not accuracy. Native full regression unexecuted.
