## Contract

- Only ordinary support helpers/controllers/wealth participants, valid rescue helpers and conditional regulation participants enter the role registry. Day reference excluded; an anchor alias is explicit, not a separate actor. A wealth product/participant is not automatically the same role as its helper. Regulation is never ordinary support.
- Mask an occurrence from the existing witness graph. Explicit roles and edge endpoints are necessary for each witness; anchor bindings are alternatives. Compare same-rule/same-target support alternatives and exact V7 threat alternatives. If a protected target or threat disappears, classify it as masked, not assistant loss. Report remaining alternatives, lost alternatives, and no-route-before-mask separately. All observed alternatives lost does not prove global necessity. Different support rule groups are not interchangeable.
- Pair masking finds joint-only dependencies absent from both individual masks. Anchor aliases excluded from pair screening. No arbitrary ranking or numerical marginal utility. Missing hour cannot yield confirmed necessity.
- Potential injury references exact V7 support/damage, rescue interference and collateral evidence. This is not exhaustive assistant injury detection. Invalid V7 references fail closed.
- Scope gaps: branch assembly as assistant (not yet represented by V7 positive role witnesses); source examples of combining hurting to preserve officer and combining resource to preserve food require additional dedicated outcome rules. Exception auxiliary roles are not inferred as assistants. Masking is not a physically changed chart and does not discover new routes or model redistribution. All necessity/effect/assistant confirmations remain null.
