# 일간 강약 혼합형 관법 — strength-hybrid-v1 설계안

상태: **C안 실험 구현 / 수치 검증 완료, 전문가 사례 및 네이티브 회귀 대기** (2026-11-24).
기존 원국·궁합·이동수 API와 점수를 변경하지 않는다. 전통 명리학 내부에서의 일관성과 설명 가능성을 목표로 한다. 실제 성격, 건강, 운세, 이사나 인생 사건의 예측력 또는 통계적 확률을 의미하지 않는다.

## 1. 결정과 근거

정성적 구조 판단을 우선하고 정량 지표는 이를 교차 확인한다. 점수가 구조를 뒤집거나 자동으로 용신을 선택하지 않는다. 결론이 충돌하면 보류한다. 월령이 유일한 판단 기준은 아니며 통근과 천간의 생조·설기·극을 함께 검토한다.

- [자평진전 論十干得時不旺失時不弱 (원문·번역)](https://www.dk-saju.com/classics/자평진전/자평진전-06-논십간득시불왕실시불약): 득시/실시만으로 강약을 단정하지 않고 통근의 경중을 본다. 장생·녹왕·묘고와 여기의 차이는 후속 관법에 포함할 수 있으나 v1은 12운성을 자동 통근표로 채택하지 않는다.
- [우연화·김만태 (2022), 천간과 지지의 상조와 상극에 관한 연구](https://www.jdaos.org/archive/view_article_pubreader?pid=jdaos-42-0-109), DOI 10.25050/jdaos.2022.42.0.109: 통근과 인성 생조의 차이, 동오행 통근과 위치의 중요성, 문헌 간 관법 차이. 일간 통근의 월>일>시>년 위치 순서를 참고한다.
- [이재승 (2019), 사주명조의 계량화를 통한 성명학적 용신법 고찰](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002532570): 공개 초록의 위치별 가중치를 비교용 중심 프로파일로 참고한다. 논문은 내격·성명학 목적이며 합충에 의한 변화를 다루지 못했다. 본 설계는 일간 고정 20점을 더하지 않고 지장간 분배·보류 규칙을 별도로 제안하므로 논문 모델의 재현이나 검증이 아니다.

문헌은 판단 방향의 근거다. 아래의 임계값·루트 범주·가중치 변형·보류 조건은 **제품의 가설적 v1 정책**으로 구분한다. 전문가 명조 검토 전 정통 관법의 유일한 공식으로 표시하지 않는다.

## 2. 입력 및 관찰값

신규 API: `analyzeDayMasterStrength({saju, policy:'strength-hybrid-v1'})`.
기존 `analyzeNatalStructure`, `analyzeNatalContext`, `analyzeNatalRelations`와 공통 오행/지장간 표를 이용한다. 연월일주 검증, 시주 null 허용. 일주 단독, 절입 미확정 명조, 소비자의 임시 시간 가정으로 연월주가 정해진 명조는 판정 대상에서 제외한다. API는 실제 출생시각을 독립적으로 검증할 수 없으므로 소비자가 provisional birth metadata를 전달하거나 호출하지 않아야 한다. 공개 계약에서 명시적인 `birthBasis: 'verified-chart'|'provisional-chart'` 입력을 요구한다. 사주 자체의 진위나 실제 운명은 검증하지 않는다.

일간을 기준으로 오행을 다음 5개 범주로 분리한다.

- peer: 비겁(동오행), resource: 인성(일간을 생함)
- output: 식상(일간이 생함), wealth: 재성(일간이 극함), officer: 관살(일간을 극함)

support = peer + resource. burden = output + wealth + officer. 세 부담 범주의 작용을 같다고 주장하지 않는다. 관찰 및 점수 내역에는 각각의 양과 위치를 남긴다. 일간 자신을 지원 천간으로 중복 계산하지 않는다.

### 2.1 득령/계절

월지 본기의 일간 대비 5범주, 월지 전체 지장간, 계절을 반환한다. 편의상 월지 본기가 peer이면 M=peer, resource이면 M=resource, 나머지는 M=burden. 이는 월지 본기 기준의 지지/부담 단서이지 시기별 사령(司令), 실제 득령, 왕상휴수사 또는 격국을 확정한 결과가 아니다. 진술축미 월지에도 동일한 규칙을 적용하되 earth-transition 태그와 사령 미판정 상태를 명시한다.

### 2.2 득지/통근 후보

각 지지에서 일간과 동오행인 지장간을 찾는다. 정확히 같은 천간과 음양만 다른 천간은 별도로 보존하되 v1 후보 존재 판정에는 둘 다 인정한다. 인성은 생조로만 분류하고 통근에는 포함하지 않는다.
한 지지에 동오행 지장간이 여러 개여도 통근 위치는 한 개로 집계하며 역할 우선순위 principal > middle > residual의 최고 역할을 사용한다. 통근 위치는 month > day > hour > year 순으로 기록한다.

- substantial root: 본기 동오행(모든 위치), 또는 중기 동오행(월지/일지).
- minor root: 위 조건에 해당하지 않는 동오행 지장간.
- none: 관측된 지지에 동오행이 없음.

이 범주는 보수적인 제품 분류다. 본기/중기/여기 분류가 고전의 장생·녹왕·묘고와 완전히 같은 개념이라는 주장을 하지 않는다.

### 2.3 득세/생극 및 투간

일간 외 연간·월간·시간 각각의 5범주와 지장간 근거를 표시한다. 각 천간이 자기 오행의 본기/중기 지장간을 하나라도 갖는 경우 anchored stem으로 분류한다(여기 단독은 minor). exact-stem 투간 후보와 same-element 대응을 구분한다.
구조 규칙용 S = anchored peer/resource 천간 수, P = 부담을 대표하는 실제 위치 수: 일간 외 anchored output/wealth/officer 천간 및 본기가 부담인 각 지지. 각 위치는 최대 1회(천간 슬롯과 지지 슬롯은 별개), P는 세 가지 부담 범주를 보존한다.
정량 지표에서는 천간과 지지를 각 슬롯에 한 번씩만 반영한다. 통근·투간·득령 보너스 점수를 별도로 더하지 않는다.

## 3. 정성 규칙

Mplus = M이 peer/resource; R = substantial root 지지 수; Rcentral = 월지 또는 일지에 substantial root 존재; S와 P는 위 정의.
다음은 내격 후보의 보수적 규칙이며 순서대로 기록한다.

| ID | 조건 | 구조적 후보 |
| --- | --- | --- |
| Q1 | Mplus && R>=1 && (S>=1 또는 R>=2) | strong |
| Q2 | !Mplus && R>=2 && Rcentral && S>=1 | strong |
| Q3 | !Mplus && R==0 && S<=1 && P>=2 | weak |
| Q4 | Mplus && R==0 && S==0 && P>=3 | weak |
| Q5 | R>=1 && (S>=1 또는 Mplus) && P>=2, 그리고 Q1~Q4 미충족 | mixed |
| Q0 | 나머지 | unresolved |

Q1/Q2와 Q3/Q4는 상호 배타적이다. Q5는 단순히 점수가 50에 가깝다는 의미가 아니라 지지와 부담이 모두 확인된 구조이다. 어떠한 조건도 실제 신강·신약의 충분조건으로 입증된 것은 아니다. 혼합형의 목적은 논리상 근거와 수치가 합치하는 경우에만 제한적인 결과를 제공하는 것이다.

## 4. 정량 보조: 지원 지수

일간 자신을 제외한 7개 슬롯의 가중치 합은 100이다. 순서는 연간/연지/월간/월지/일지/시간/시지.

| profile | 연간 | 연지 | 월간 | 월지 | 일지 | 시간 | 시지 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| balanced | 5 | 9 | 10 | 30 | 21 | 10 | 15 |
| distributed | 7 | 10 | 12 | 25 | 20 | 11 | 15 |
| month-heavy | 4 | 8 | 9 | 35 | 22 | 8 | 14 |

balanced 위치표는 2019년 논문의 공개 초록에 나타난 위치 가중치를 참고한 것이며 다른 두 표는 민감도 분석용 제품 가설이다. 월지>일지>시지>연지 순서를 유지한다. 일간 20점과 논문의 원래 분류 임계값은 채택하지 않는다.

지장간 내부 분배도 단일 정답으로 가정하지 않는다. 기존 HIDDEN_STEMS_VERSION 기준 역할별 가설이다.

| role profile | 3개 지장간: 정기/중기/여기 | 2개: 정기/여기 |
| --- | --- | --- |
| base | 60/30/10 | 80/20 |
| principal-heavy | 75/20/5 | 90/10 |
| distributed | 50/30/20 | 70/30 |

분배 합은 1이다. 실제 월률 사령 일수, 물리량, 관측된 통근력으로 해석하지 않는다. 지지의 표면 오행은 같은 지지에 별도로 가산하지 않는다.

각 천간 슬롯은 해당 범주로 가중치 전체를 배분하고, 지지 슬롯은 지장간 분배율에 따라 5범주로 나눈다.
I = sum(각 슬롯 가중치 × 해당 슬롯의 peer/resource 분율), 0~100.
3×3=9개 시나리오를 실행해 전체 5범주 내역과 중앙 프로파일(balanced×base), 최소/최대 지원 지수를 반환한다. 부동소수 경계 문제를 피하기 위해 100분율 정수 가중치를 곱한 정수(0~10000)로 비교하고 출력 때만 100으로 나눈다.

후보 임계값: 0~35 weak, 35 초과~65 미만 middle, 65~100 strong. 두 경계는 제품 가설이며 논문의 수치를 옮긴 것이 아니다. 30/70과 40/60으로도 민감도를 검사해 경계 변경에 따른 판정 변동을 표시한다. 최종 확정 조건은 기본 35/65뿐 아니라 이 두 대체 경계에서도 같은 결과가 유지되는 경우로 제한한다(즉 strong이면 min>=70, weak이면 max<=30, mixed이면 min>40 && max<60). 정확한 중화 여부나 확률은 반환하지 않는다.

시주가 null이면 분모를 75 등으로 재정규화하지 않는다. 각 시나리오에서 알려진 슬롯 합을 lower, 누락된 시간+시지 가중치 전체를 더한 값을 upper로 둔다. 가능한 실제 시주를 추측하지 않고 보수적인 범위를 제공한다. 관측되지 않은 지지/천간의 통근과 투간은 없다고 단정하지 않는다. 완전 시주에서만 최종 category를 허용한다.

## 5. 예외 및 최종 판정 게이트

아래 플래그가 하나라도 있으면 score로 보정하거나 확정하지 않고 review-required 상태. 형·파·해·원진 자체를 기계적 감점으로 사용하지 않는다.

- day-stem-combination: 일간과 다른 천간의 합. 합화/쟁합/투합 판단은 별도 정책.
- branch-formation: 원국에 완성된 삼합/방합, 또는 월지가 포함된 왕지 반합 후보. 합국 작용과 합화를 판단하지 않고 보류.
- root-or-month-clash: 월지 또는 substantial root 지지가 육충에 포함. 뿌리 제거/파괴를 자동 처리하지 않음.
- possible-special-pattern: 9개 시나리오 중 어느 하나의 지원 지수가 <=15 또는 >=85 (시주 결측에서는 시나리오 범위 전체가 해당 극단 구간에 포함될 때만), 또는 관측된 동오행 통근 없음+앵커된 지지 천간 S=0+M이 burden. 종격·전왕·화격의 확정이 아니라 전문 검토 신호. 모든 특수격을 검출한다고 주장하지 않는다.
- provisional-chart: 연월주가 절입 경계에서 임시 시각으로 선택됨. 강약 계산 자체를 하지 않음.
- missing-hour: 최종 판정 금지. 관측된 정성 후보와 지수 범위만 노출하며 review-required보다 낮은 우선순위.

판정 순서: 입력 오류/임시 명조 → 구조 관찰 및 수치 범위 → 예외 플래그 → 시주 결측 → 정성/수치 합치.
완전 원국에 대해 예외 없음 + Q1/Q2 + 전체 시나리오에서 strong이 모든 임계값 프로파일에 안정적이면 candidate-strong; Q3/Q4와 stable weak이면 candidate-weak; Q5와 stable middle이면 mixed-tendency. 그 외는 unresolved. 최종 판정은 제품 내격 모형의 후보이며 실제 명리 전문가의 확정이나 운세 예측이 아니다. 혼합형은 미분류를 허용한다. 보류 비율이 높다는 이유만으로 경계를 낮추지 않는다.

## 6. API 계약

```js
analyzeDayMasterStrength({
  saju,
  policy: 'strength-hybrid-v1',
  birthBasis: 'verified-chart' // calendar-resolved, not verified identity
})
// {
//   version, hiddenStemsBasis, completeHour,
//   status: 'candidate'|'unresolved'|'review-required'|'partial'|'provisional',
//   category: 'strong'|'weak'|'mixed'|null,
//   evidence: {month, roots, stems, projections, relations, qualitativeRule, counters},
//   quantitative: {baseline, min, max, scenarios, thresholdSensitivity},
//   reviewFlags: [...]
// }
```

provisional 입력에는 정성/정량 결과를 생성하지 않는다. partial/review-required/unresolved의 category는 null. 루트 증거·월지 본기와 해석 후보를 구분한다. 데이터 전송/개인정보 수집 없음; 결과에 생년월일 원본이나 호출자 임의 메타데이터를 포함하지 않는다. API는 순수 함수, 정렬 및 시나리오 순서 결정적, 입력 객체 비변경. 앱에서는 일본어 표시 및 설명을 소비자에서 담당한다.

## 7. 검증 계획 및 릴리즈 게이트

1. 독립 명리표: 일간 10×대상 10 천간 분류, 12지지 지장간, 위치와 동오행/동천간 분리.
2. 수치: 각 역할 프로파일 합, 위치 합 100, 5범주 합=100(완전), 범위 0~100, 모든 시나리오/임계값 경계(30/35/40/60/65/70), 동일 슬롯 지장간 중복 금지. 누락 시주 범위에 모든 합법적인 시주 완성이 포함되는지 검사.
3. 구조: 득시불왕/실시불약 예제, 월지 본기 생조와 통근 분리, 중기/여기만 있는 경우, 자평진전 예시의 원문 출처와 해석 차이 기록. 예외 플래그와 Q1~Q5 순서, 구조와 점수 충돌 시 보류.
4. 문헌 사례 + 전문가 검토 세트: 검토자별 독립 판정(강/약/중간/특수/불확실), 원국과 근거, 출처·관법 버전. 훈련/정책 조정용과 보류된 평가용을 분리. 평가에는 coverage(판정 비율), 판정된 사례 일치율, 전체 혼동행렬, 검토자 간 일치 및 보류율을 함께 기록. 실제 미래 예측 정확도와 혼동하지 않는다. 공개 범위는 테스트셋 검토 후 승인.
5. 1900~2100 달력 지원 범위와 Tokyo 1970+ 실제 원국의 넓은 표본, 시주 누락/절입/역사적 시각 예외, 레거시 이동수·궁합 회귀. npm test 및 소비자 빌드 통과 후 고정 SHA 갱신.
6. 테스트 없이 수치 변경 금지. 데이터로 임계값을 튜닝할 때 정책 버전 분리. 사령·12운성·합화·종격/격국·용신은 별도 ADR과 검증 후 추가. 사용자 UI에서 결과를 공개하기 전 보류 사례와 설명 품질 검토.

## 8. 구현 순서

A: 입력 계약·5범주 분류·근거 수집.
B: 9개 수치 시나리오와 범위/경계 민감도.
C: 구조 규칙 및 예외 게이트.
D: 문헌/전문가 비교 검증, 고정 fixture, API/README.
E: saju-friends 개인 상세 해석에 선택적으로 노출. 기존 친구 관계지도와 영끌각 v6에 자동 반영하지 않음.

## 9. 구현 및 검증 기록

API는 policy와 birthBasis를 명시해야 한다. 잘못된 입력은 SajuError(strength-input/strength-policy/strength-birth-basis 또는 기존 pillar 검증 오류)로 반환한다. quantitative.scenarios에는 정수 hundredths lowerUnits/upperUnits, knownWeight/missingWeight, 5범주 값과 소수점 지원 범위를 기록한다. stableCategory는 모든 임계값에 일치하는 경우만 반환한다. 실험 구현은 evidence, quantitative, index 세 모듈로 구성하며 [ADR](adr/0001-strength-hybrid.md)을 따른다.

신규 테스트 10개 로직을 실제 GitHub 소스와 달력 데이터를 사용한 V8 실행으로 통과했다(ESM import/export 변환 및 소형 assertion harness; native Node runner 아님). 커밋 5bb41cf의 소스를 다시 읽어 같은 테스트를 통과했다. 첫 표본은 1900~2100년 5년 간격, 1/4/7/10월 15일, 시주 결측 및 4개 시각, 지원되는 서울/도쿄 시간대; 1,360개 입력이다. 두 번째 표본은 1990~2000년 매월 10/20일 6개 시각, 도쿄; 1,584개 완전 입력이다.

| 상태 | 첫 표본 | 두 번째 표본 |
| --- | ---: | ---: |
| review-required | 838 | 1155 |
| partial | 164 | 0 |
| unresolved | 331 | 388 |
| candidate:strong | 0 | 7 |
| candidate:weak | 9 | 16 |
| candidate:mixed | 18 | 18 |

합계 2,944개 입력, 첫 표본 328개 시주 결측(예외가 동시에 있으면 review-required 우선). 완전 입력 2,616개 중 후보 68개(약 2.6%). 균등·무작위 인구 표본이 아니며 서울/도쿄 동일 명조 중복 가능. 이 수치는 정책 커버리지 진단이지 해석 정확도가 아니다. 신강/신약/혼재 각각의 실제 달력 입력과 결과를 회귀용으로 고정하되, 전문가 라벨로 취급하지 않는다. 낮은 커버리지를 해결하기 위해 임계값을 임의로 완화하지 않는다. 전문가 명조 비교, 실제 npm test 전체, 소비자 빌드는 미실행. 배포 전 검증 게이트 유지.

## 10. 문헌 대조 1차

[적천수천미 명조 대조](strength-reference-v1.md)에서 26개 개발 사례와 v1 결과를 기록했다. 특수 검토 누락, 정성 규칙의 부담 반영 부족, 중화와 지수의 차이를 확인했다. v1 임계값과 소비자는 변경하지 않는다. 독립 평가 세트와 전문가 검토는 여전히 대기한다.

## 11. 후속 범위 결정

특수격 해석은 현재 개발 범위에서 제외한다. v1은 기준 비교용으로 보존하고 [일반 강약 v2](strength-ordinary-v2.md)를 별도 정책으로 구현한다.
