# Pattern outcome evidence v2: hidden and branch assembly access

Opt-in `analyzePatternOutcomeV2({saju,birthBasis,policy:PATTERN_OUTCOME_V2_VERSION})` (`pattern-outcome-evidence-v2`). V1 and V1–V10 pattern outputs remain frozen; no consumer or authority migration.

## Evidence boundaries

- `outcome-access.js` consumes existing V10 stem-force and core formation evidence. Each hidden stem retains its physical branch slot, role, exact visible projections, clash/formation contacts. Projection and principal/middle/residual are observations, not access permission or force. The current implementation enumerates all hidden controller roles as conditional witnesses (including residual); no efficacy claim.
- Only complete three-harmony and seasonal groups with a known associated element become group nodes. Pair candidates and six-harmony are excluded from group action. Each node references the original formation, three branch slots, competing/overlapping formations, contextual screen and limitations. Repeated branch alternatives share slots; they cannot be summed. Group-to-constituent-hidden edges are prohibited. Visible stem at a member pillar is a separate slot, with shared-pillar metadata. Edges are directed element relationships, not actual transformation. No generated stem, yin/yang or specific ten-god is inferred for a group.
- `outcome-extended.js` adds five rule templates: officer group output injury and resource intervention; blade hidden officer/killing controller injury, visible resource-output combination and resource control. Rescue binds the exact damage witness and never removes it. Existing rule results are copied unchanged, while V2 review status and conditional helper list may reflect new witnesses. Day reference remains only a proxy in blade rules.
- Formation context is obtained through the existing public core function, incurring an additional observation pass. No cache or refactoring of existing runtime code. Branch access, efficacy, transformation, protection, selection, strength and special chart interpretation are unresolved. Other families retain V1 outcomes; generic access edges are available for future rule expansion.
