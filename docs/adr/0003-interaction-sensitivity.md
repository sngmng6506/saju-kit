# ADR-0003: Separate interaction evidence from hypothetical strength effects

**Status:** Accepted for experimental diagnostics.

## Context
Ordinary v2 records frequent formation/clash caveats but cannot distinguish which roots or weighted slots matter. A fixed adjustment would conflate an observed relationship with an operative transformation or loss.

## Decision
Add neutral occurrence-aware interaction context to core and a separate one-relation-at-a-time sensitivity feature that reuses frozen v2 and v1 quantitative assumptions. Do not modify existing classifiers or apply scenario results to actual chart strength. No special-pattern analysis.

## Consequences
Traceable hypotheses and useful regression evidence without an unvalidated force model. Scenarios intentionally omit combined effects and do not imply actual causal direction. [Contract](../interaction-sensitivity-v1.md) defines their scope and verification gates.
