# ADR-0004: Keep root quality and protective paths as neutral evidence

**Status:** Accepted for experimental research.

## Context
Ordinary v2 misses strong textual charts despite real root positions. Aggregate support mass and principal branch counts cannot represent position-specific root evidence or controlling chains.

## Decision
Add a core root-dynamics module. Keep literal hidden-stem matches separate from a named twelve-stage convention and seasonal context; represent control/protection/mediation by actual distinct slots with explicit distance and direction. No inference of effective strength, successful mediation or special patterns. Do not change v1/v2 or tune on inspected reference cases.

## Consequences
Traceable richer observations for future decision policies. Many paths share slots and must not be summed. Independent interpretive validation and native regression remain release gates. See [contract](../root-dynamics-v1.md).
