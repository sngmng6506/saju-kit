# Outcome decision V10: explicit abstention release

Public opt-in `analyzePatternOutcomeV10` / `pattern-outcome-decision-v10`, distinct from existing `pattern-useful-element-v10`. This release implements the judgment boundary, not an effective final classifier.

## Authority and contract

Seven independent release axes: pattern selection, formation, breakage, rescue, assistant, purity, clarity. Each has an explicit unauthorized state, null receipt, and release-level validation blockers. Release metadata is constructed from private immutable definitions, not caller flags, fixture labels, root/locality screen counts or external approvals passed in the request. There is deliberately no activation switch or decision algorithm in this release. A future authorized policy requires a new implementation, independent validation and release. Never interpret abstention as a negative verdict.

The V10 API calls efficacy once, forwards only saju/birthBasis and pinned policy, and preserves inherited fields except version/scope. Candidate-scoped formation, breakage, rescue, assistant and clarity decisions refer to exact witnessed relations, regulation/exception separately, threats and alternative routes, assistant dependency and injury, and conflicts. Global pattern decision exposes a usable existing family hypothesis only as unconfirmed; global source purity exposes observed motifs only. Every value remains null. Missing hour, storage uncertainty, unsupported cases and no-covered-witness are different blockers. Invalid candidate evidence/coverage fails closed. A missing witness is not proof of absence. Source labels do not validate empirical life predictions.

## Validation requirements before authority

- Full native integration/regression and exact versioned release evidence.
- Prospective source-adjudicated full charts outside development exposure, negative and ambiguous cases, per-axis independent labels and explicit disagreement.
- Separate effective-force, transformation, protection and residual-threat conditions; no automatic cancellation, no proxy threshold chosen to maximize development recall.
- Axis-specific evaluation with fixed denominator, abstention and selective agreement. No pooled score or claims of real-world predictive validation from classical concordance.
- Explicit review of release criteria and consumer opt-in. Existing consumers and APIs unchanged.
