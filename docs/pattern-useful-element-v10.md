# Relative force evidence v1 / pattern v10

Source: [論用神格局高低](https://www.donglishuzhai.net/chapter/3725.html), [parallel](https://www.kaucim.ai/bazi/ziping-zhenquan/lun-yong-shen-ge-ju-gao-di). The chapter distinguishes controller, controlled actor and day capacity; excessive or deficient food/killing and shallow day roots are different problems. This policy does not translate the source's social-status claims into predictions.

Core observeRelativeForce takes stem-force v1 observations. Eight Boolean axes represent evidence presence, not independent resources or numerical weights. The partial order compares the sets of true axes only on complete visible-to-visible distinct physical slots; opposing differences yield mixed evidence, equality yields equal evidence profiles, not equal force. Hidden occurrence access is unresolved. Common root/support references are explicitly retained, not summed. Season and month principal are separate observations, not additive weights. A positive root does not establish 旺 or 有力.

Directed generating/controlling edges report source pressure, possible local protection, combination/group contacts, clash exposure, locality and root availability. The screen is intentionally strict engineering policy, not a sufficient classical efficacy condition. It never removes a threat because a possible protection path exists. A screen met means those particular checks passed only. Food-killing-day triads use actual distinct visible food and killing stems, actual directed control, day pressure and output edges; concerns are not effective-force judgements. No threshold, strength score, confirmed efficacy, 成敗 or authority. V10 binds these references to v9 routes and named role witnesses and retains all older fields apart from version. No consumer update.

Initial isolated JavaScript benchmark: 81 reference charts, 240 synthetic charts and one source-inspired schematic; 20 actual modules with adapted ESM, not full public wrapper. 20,149 edges, 15 visible food/killing/day triads, 7,816 legacy links and 9,198 named-path edge references. Screens: 63 root/locality checks met, 15,256 require review, 4,830 unresolved. Pair comparison: 18,847 noncomparable, 41 equal evidence, 197 right evidence dominates, 309 left evidence dominates, 443 mixed, 312 unresolved. A final narrow correction checks the actual helper rather than the first source in mediation paths; it does not change pair comparisons or screen conditions. Native regression and complete public wrapper remain unexecuted. Synthetic pillars individually valid but not necessarily calendar-consistent. No independent effective-force labels; these are structural test counts.
